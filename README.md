## How to run the code

Keep the Python file and Excel workbook in the same folder.

Install dependencies:

```bash
pip install -r requirements.txt
```

Run:

```bash
python data_analytics_analysis.py
```

The script reads the `Raw_Data` sheet and creates `analysis_output.xlsx` containing the generated analysis tables.

## Important data-handling note
The original `Raw_Data` sheet is used as the source for the checks. The script does not overwrite the raw data.
